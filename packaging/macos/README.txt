Compress Images for macOS

Open Compress Images.app to start the graphical application.
For terminal use, run CompressImagesCLI.command from Terminal, for example:

  ./CompressImagesCLI.command 1 --max-dimension 2400

The app contains Python, GTK4/PyGObject, ImageMagick, FFmpeg and libheif.
Original images are never changed. Settings are stored in
~/Library/Application Support/compress-images.
