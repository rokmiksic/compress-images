# Contributing

Contributions are welcome under the MIT License.

## Development

1. Fork the repository and create a focused branch.
2. Make the smallest change that solves the problem.
3. Run the syntax checks and test the CLI on a temporary directory.
4. Update documentation when behavior or installation changes.
5. Open a pull request with a clear description and test results.

Do not commit personal images, generated packages, credentials, tokens, or local settings. The project must preserve original images and must not silently overwrite output files.

By submitting a pull request, you agree that your contribution is provided under the same MIT License. No Contributor License Agreement is required.
